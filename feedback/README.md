# GREVIX AfterCode — Challenge Card 2 Feedback

## Feedback Received

Three friends reviewed CampusMate AI and suggested adding a chatbot to explain notices, reminders for assignment and exam deadlines, shared and verified college notice updates, branch/semester filters, calendar integration, and other student productivity features.

## Improvements Implemented

* **Ask CampusMate:** Added a local, rule-based Q&A prototype that answers questions using notices saved in the current browser.
* **Upcoming Deadline Reminders:** Added an in-app section showing saved notices dated within the next seven days, with deadlines within the next three days highlighted.

## Current Limitations

The application does not yet use a real AI API, shared cloud database, verified live college notice feed, or push notifications. The Q&A and reminders use locally saved notice data.
